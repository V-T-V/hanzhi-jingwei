# 汉志经纬 · 漢書地理志

[![CI](https://github.com/V-T-V/hanzhi-jingwei/actions/workflows/ci.yml/badge.svg)](https://github.com/V-T-V/hanzhi-jingwei/actions/workflows/ci.yml)

《漢書·地理志》（東漢·班固 撰，唐·顔師古 注，志第八，上下两卷）数字人文站——
十四部域一百三郡国舆图、元始二年户口、郡县循读、全书志文检索、域分风俗十三区。
文本自 kanripo《前漢書》（KR2a0007，文淵閣四庫本）卷二十八抓取解析，上下两卷俱全。

## 全书（如实标注）

原书为《漢書》一百二十卷之志第八，地理志**上下两卷俱全，无缺卷**。本站语料：

- 志文正文 + 双行夹注（顔師古注等，括号内小字呈现）——**上下卷全志收录**
- 卷末「卷二十八上/下考證」两节系四库馆臣所撰，**剥离未入正书语料**（README 与站内「关于」两处声明）
- 底本系清四库写本：避讳改字从原书（玄→元，故志作「**元菟**」；弘作 𢎞 构形），
  站内正名归一为 玄菟/雁門/真定/河間/城陽；kanripo 生僻字实体（&KR####;）显示为 □

## 功能

- **舆图**：郡治印随部域设色（底栏「玄墨」开关转单色；大小随属县数）· 部域晕开关
  （治所凸包示意，非考证边界）· zoom≥6 首县微点（首县例与郡同治）· zoom≥7 郡名常显 ·
  点击郡国入郡卡（户口原书句 · 辖县名录 · 名物徽标 · 阅原文 · 书签）
- **循郡而读**：左列纲目按「部域—郡国—属县」三级展开，点击展开属县名录
- **郡卡**：元始二年户口**原书句逐字保留**（「戸十一萬八千九十一口四十七萬五千九百五十四」）
  并注阿拉伯数字对照；辖县「入表 N / 原文载 M」如实并陈；徽标（铁官/盐官/工官/橘官/木官/祠/莽改）
  出自注中实证，点击徽标直达郡条原文命中处
- **阅读器**：郡条原文懒加载（逐县一行重构，注在括号小字；字字皆志文）·
  志序/总计/四库提要/域分各成篇 · 卷内县目跳转 · 夜读 ☾ · TTS 朗读 🔊 · 字号 A−/A+ · 存 .txt
- **全书检索**：顶栏检郡县名（回车直达）；「在全书志文中检索」遍检 119 篇
  （懒加载分片 + Worker 纯数据扫描，片段预览，点击直达命中处）
- **域分风俗**：十三区域（秦/魏/周/韓/趙/燕/齊/魯/宋/衛/楚/吳/粵）分野与风俗原文，
  底栏「☲ 域分」入
- **三维形胜**（[3d.html](3d.html) / 底栏 ⛰）：MapLibre 真地形（1.35× 夸张）上观百三郡国，
  圆径随属县数、色随部域；**志文柱**：条目文量 ≥500 字的郡国立六棱文柱
  （青绿系随高渐深，柱高随文量 log 映射 0.4–5.0 km——示意尺度，非实测）；
  不满阈值者不立柱——志文简省之实。软渲染截图见 `docs/evidence/3d-soft.png`
- **汉唐对照**（底栏「漢唐」）：汉 103 郡国（元始二年·公元 2 年）↔ 唐 227 州府
  （元和八年·813）郡治↔州治对照——同名同城 3 · 承名 48 · 同名迁治 1 · 无对应 51 如实分档
  （含元和志缺卷归因：淮南整道佚之寿/庐/扬、卷十九/二十之幽州、卷二十三之荆/金州、
  卷二十五/二十六之宣州）——按汉部域分组 + 汉志原文句 × 元和原文句样例 +
  ↗元和 深链（`../YHJZ/#dao=…&zhou=…`，姊妹站元和经纬数据**只读**）
- **书签/漫游**：郡卡 ☆ 收藏（localStorage）；⚑ 漫游随机入郡
- **郡国导出**（底栏「⤓ 導出」）：郡国对照 / 县名录 CSV（带 BOM）+ 郡治点位 KML / GeoJSON，
  与 `tools/export_data.py` 同口径（103 郡国 + 1,578 县），整编坐标逐行注明
- **PWA**：Service Worker 三级缓存，首访后全志离线可读（离线四验见 `tools/offline_check.py`）

## 数据口径（自源本解析，凡数字出自脚本 · docs/stats.json）

- 抓取《前漢書》卷二十八上/下全志 + 卷首提要，语料（去空白）**92,419 字**
  （志文正文+顔師古注+提要；考證两节剥离）
- 郡国条目 **103**（京兆尹→長沙國，上卷 52 · 下卷 51，与志总「郡國一百三」密合）；
  **县名录与原书逐郡「縣N」对账 103/103 全合**，入表县 **1,578**
  （志总自报 1587，差 9 系传世文本分计与总数之歧，如实入档）
- 元始二年户口：郡分计 戸 12,296,468 / 口 57,671,401；志末总计
  **戸 12,233,062 / 口 59,594,978**（分计与总计不合，两存之）
- 坐标：郡治今地人工整编全覆盖（src:"derived"，置信确 58 / 推 45）；
  郡治从首县例（例外 2 注明）；属县但存名录，不做定位臆测
- 名物注记：莽曰 **671** · 祠 48 · 鹽官 23 · 铁官 33（鐵/鐡二形并计）· 工官 9 · 橘官 1 · 木官 1
- 域分风俗 13 区（秦地→粵地，11,541 字）
- 部域分组（司隶/豫/兖/青/徐/冀/幽/并/朔方/涼/益/荆/扬/交趾）为西汉末监察部域
  **整编示意**（淮陽/梁/魯从豫、桂陽从荆等从通说），非考证边界

## 风险与已知之阙

- 郡治坐标为今地整编（非考古定位），置信「推」级多为故城遗址或首县例推定；
  边郡（玄菟/乐浪/交趾/日南等）治所今地或涉外，从学界通说
- 合并裸县整理表（SPLIT_FIX，9 处）系全角空格缺如所致连写的拆分，皆经县数对账与县名互证；
  kanripo 实体字县名显示为 □（3 处），原文档保留实体
- 部域归属之通说异辞（如淮陽国属豫属兖）本站从一而注，可在 lint 与 README 复核
- 汉唐桥为治所近距（≤35 km）+ 同名/承名的自动匹配：同名异地不入档，
  元和缺卷所致无对应逐条注明卷次；承名整编 5 条（汝南→蔡州等）书证在脚本注记
- 抓取源为 GitHub raw 在线服务，重抓请 `python tools/fetch_text.py`（断点续抓）
